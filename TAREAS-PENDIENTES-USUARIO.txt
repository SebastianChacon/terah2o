1. CONVEX - ARCHIVOS GENERADOS (CRITICO)
   ------------------------------------------------------------
   El build de produccion falla porque faltan archivos generados
   de Convex en: convex/_generated/server.ts

   SOLUCION: Ejecutar el proceso de Convex para regenerar:

     cd app
     npx convex dev

   Esto iniciara el servidor de desarrollo de Convex y generara
   los archivos necesarios en convex/_generated/.

   Si no tienes Convex configurado aun:
     npx convex init
     npx convex deploy

   Sin esto, la app funciona en dev pero NO se puede hacer build
   de produccion.

2. API KEY DE GEMINI (FUNCIONALIDAD IA)
   ------------------------------------------------------------
   Los botones de IA en la Bitacora Integral (Global Audit,
   Diagnostico Calidad, Predecir Stock, Auditoria Economica)
   requieren una API key de Gemini configurada.

   Verifica que tu archivo .env.local tenga:
     GEMINI_API_KEY=tu-api-key-aqui

   Y que la ruta /api/gemini este configurada con esa key.

3. VARIABLE DE ENTORNO CONVEX (CONECTIVIDAD)
   ------------------------------------------------------------
   Verifica que .env.local contenga:
     NEXT_PUBLIC_CONVEX_URL=tu-url-de-convex

   Sin esta variable, las consultas a Convex no funcionaran
   y las tablas de la bitacora mostraran estados vacios.
